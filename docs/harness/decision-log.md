| 2026-08-20 | Poppler, pdfplumber, OCR fallback으로 PDF를 처리한다 | PDF에 텍스트와 이미지가 함께 있기 때문 | 사용자 확인 필요 |
| 2026-08-20 | API 상태 관리는 TanStack Query를 사용한다 | 클라이언트 API cache, invalidation, mutation 상태를 일관되게 관리하기 위해 | 사용자 확인 필요 |

| 2026-08-20 | Git 기본 브랜치는 `main`, remote는 `git@github.com:KodywiththeK/lesson.git`로 둔다 | 사용자가 지정한 저장소에 규칙적으로 커밋하며 작업하기 위해 | 사용자 확인 필요 |
| 2026-08-20 | 커밋 메시지는 `type(scope): summary` 형식을 따른다 | 작업 이력을 자동 에이전트가 읽고 추적하기 쉽게 하기 위해 | 사용자 확인 필요 |
| 2026-10-15 | 날짜·월·시간·일시 입력은 기본 브라우저 입력을 쓰지 않고 `src/components/operations/date-time-fields.tsx`의 shadcn 조합 필드를 쓴다. 텍스트 직접 입력과 선택기를 함께 제공하고, 시간은 시·분 1분 단위이며, 빈 일시는 사용자가 날짜·시·분을 모두 고를 때까지 값을 채우지 않는다 | 브라우저마다 다른 기본 입력을 없애고 모바일·데스크톱 선택 경험과 접근 가능한 이름을 통일하기 위해. 공식 shadcn에 단일 DatePicker/TimePicker가 없어 조합 패턴으로 표준화 | 사용자 확인 필요 (예: 원 단위 외 포맷 요구, 선택기 단독 입력으로 변경) |
| 2026-10-15 | 원 단위 금액 입력은 `min={1} step={1}` 정수로 둔다. 쉼표 문자 입력은 별도 질문 후 설계한다 | `min={1} step={1000}`이 유효값 격자를 `1, 1001, …`로 만들어 `140000`을 거부했다 | 쉼표 입력 UX가 확정되면 공통 금액 입력으로 교체 |
