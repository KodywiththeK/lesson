# 개인레슨 표시·외상 회차·달력 탐색 개선 증거

## 발견과 계획

- 연결 요구사항: 2026-10-27 사용자 확정 계획의 상태 태그·악기 태그, 외상 예정과 미정산 정산, 유료·서비스 회차 분리, 4건 이상 날짜의 확대 달력. 인수 기준은 `docs/product/acceptance-scenarios.md`에 반영했다.
- 기존 온보딩 작업은 보존했다. 색상 관련 앞선 변경과 겹치는 문서는 해당 문장만 갱신했다. 후속 요청에 따라 이번 작업의 두 migration만 원격에 적용하고 이번 변경만 커밋한다.
- 가독성: 상태 문구·색상 계산은 화면 밖의 명명된 함수와 badge에 모으고, 중첩 삼항식을 피한다.
- 예측 가능성: 일반 예약과 외상 예정의 선택을 명시하고, 정산 순서·차감 출처·환불 가능 범위를 DB에서 결정한다.
- 응집도: 회차 회계와 감사 이력은 migration RPC, 악기 표시와 호버 상호작용은 레슨 뷰 가까이에 둔다.
- 결합도: 온보딩 파일과 기존 일정 수정 흐름을 건드리지 않고 회차권·개인레슨 경계에만 새 계약을 더한다.
- simplify 목표: 반복 조회와 불필요한 조건 분기, 행 전체 색상 적용을 줄인다.

## Supabase와 데이터

- 새 파일 `supabase/migrations/20261027144316_private_lesson_credit_and_service_tickets.sql`은 외상 선택, 미정산·정산 이력, 서비스 잔여와 사용 출처, 원장·데스크/담당 선생님 범위의 조회 및 RPC 검증을 담는다. 새 9인자 회차권 등록 RPC는 유료 양수 또는 명시적 서비스 0원만 받는다. 최종 검토에서 이전 앱의 8인자 유료 등록 호출이 사라지는 회귀를 실패 테스트로 확인해 양수 결제만 허용하는 호환 함수를 추가했다.
- 실제 사용은 등원 때만 기록한다. 예정 외상은 회차를 예약하지 않으며, 구매 후 과거 수업을 등원 처리한 경우도 미정산 생성 직후 정산을 시도한다. 이미 환불된 유료 출처의 출석 취소는 막고, 서비스 회수는 예정 예약 한도를 확인한다.
- 기존 회차권 예약 가드의 만료일 축소 검사는 외상 예정이 일반 예약처럼 계산되지 않도록 수정했다.
- 새 회차권 등록의 내부 구현이 행 ID를 반환하지 않아, 등록 직후 트리거가 현재 트랜잭션의 새 등록 ID를 전달하고 공개 RPC가 해당 행만 갱신하도록 했다. 동시 등록의 생성 시각 정렬에 의존하지 않는다.

## Consolidate와 남은 위험

- 가독성: 출결 상태 문구와 악기색은 독립 함수로 읽히고, 외상·서비스 선택은 사용자가 직접 확인한다.
- 예측 가능성: 금액 0원 일반 등록 우회를 닫고, 정산은 같은 학원·원생·악기 잠금과 감사 기록 안에서 수행한다.
- 응집도: 회차 정산·환불·취소 제약은 DB 함수에, 표·달력 표시 정책은 관련 컴포넌트에 배치했다.
- 결합도: 공통 Badge의 기본 스타일만 흰색으로 조정하고 도메인 상태는 전용 badge로 유지했다. 온보딩 변경은 보존했다.
- simplify 결과: 표의 반복 `find`와 달력의 중첩 삼항식을 제거하고 악기색 적용 범위를 카드/악기 태그로 좁혔다. Critical 품질 문제는 남기지 않았다.
- 원격 DB 제약·이력과 원장 문맥의 등록 RPC는 확인했지만 실제 브라우저 로그인 세션의 역할별 조작과 두 세션 동시 등록·취소를 수행하지는 못했다. 데모 E2E는 화면 표시를 검증하며 새 외상·서비스 정산 경로는 격리 SQL 하네스가 검증한다. 데모 상태 저장소는 새 정산 회계를 완전히 모사하지 않으므로 그 경로의 종단 E2E는 후속 보완이 필요하다.
- Supabase advisor의 `authenticated_security_definer_function_executable` 경고는 기존 공개 RPC에도 나타나는 권고다. 이번 RPC는 함수 안에서 인증·학원 역할을 확인하며 실행권은 `authenticated`에만 부여했다. [검토 기준](https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable).
- 적용 후 Security Advisor에는 위 실행 가능 함수 62건, 기존 함수 검색 경로 1건, private 가입 테이블 정책 없음 2건(정보), 비밀번호 유출 검사 비활성 1건이 보였다. Performance Advisor에는 미색인 FK 83건(정보), 미사용 인덱스 13건(정보), 복수 허용 정책 19건이 보였다. 새 외상 테이블에는 조회 정책을 만들었고, 나머지 기존 경고는 이번 변경 범위에서 수정하지 않았다.
- push는 수행하지 않는다.
