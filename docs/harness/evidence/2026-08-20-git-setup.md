# 2026-08-20 Git 세팅 증거

## 목표

사용자 요청에 따라 저장소를 Git으로 초기화하고, `main` 브랜치와 GitHub remote를 기준으로 앞으로 작업 단위마다 커밋하는 규칙을 만든다.

## 반영 내용

- `git init -b main`으로 저장소를 초기화했다.
- `origin` remote를 `git@github.com:KodywiththeK/lesson.git`로 연결했다.
- `docs/harness/git-workflow.md`에 커밋 컨벤션과 커밋 전 체크리스트를 추가했다.
- `AGENTS.md`, `docs/harness/commands.md`, `docs/harness/decision-log.md`에 Git 규칙을 반영했다.
- 생성 캐시인 `*.tsbuildinfo`는 `.gitignore` 기준에 따라 커밋하지 않는다.

## 커밋 컨벤션

형식은 `type(scope): summary`다.

예시:

- `docs(harness): Git 워크플로 기준 추가`
- `feat(ticket): 출석 기반 회차권 차감 규칙 추가`
- `test(ticket): 회차권 중복 차감 방지 테스트 추가`

## 검증 결과

| 명령 또는 확인 | 결과 | 비고 |
| --- | --- | --- |
| `pnpm test:run` | 통과 | unit/component 14개 테스트 통과 |
| `pnpm lint` | 통과 | `eslint .` 기준 |
| `pnpm typecheck` | 통과 | `tsc --noEmit` 기준 |

## 남은 작업

- 원격 push는 사용자가 요청하거나 원격 반영이 필요한 시점에 수행한다.
