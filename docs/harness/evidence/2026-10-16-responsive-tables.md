## 품질 정리

- 코드 단순화: 폭별 목록을 별도로 렌더링하던 회차권·레슨수입 중복을 제거했다.
- 재사용한 추상화: 기존 shadcn `Table`을 확장해 데이터 렌더링은 한 번만 수행한다.
- 테스트 정리: 구현 세부 class보다 사용자-visible 셀 항목명과 브라우저에서 계산한 레이아웃을 검증한다.
- 가독성: 셀 `label`은 헤더와 같은 업무 용어를 사용한다.
- 예측 가능성: 화면 폭이 바뀌어도 목록 순서·액션·데이터가 유지된다.
- 응집도: 반응형 배치 규칙은 공통 CSS에, 각 화면의 항목 의미는 해당 표에 둔다.
- 결합도: 화면별 비즈니스 mutation은 표 컴포넌트나 CSS에 이동하지 않았다.
- simplify 결과: 단일 표로 모바일/태블릿/데스크톱을 표현하며 불필요한 가로 스크롤 래퍼를 제거했다. 헤더 액션 다이얼로그의 열림 상태를 화면이 소유해 시트 애니메이션 종료에도 유지했다.
- 코드 품질 리뷰: 세 묶음 에이전트의 TDD·파일별 정리 후 리드가 diff와 4폭 E2E를 재검토했다.
- 남긴 Warning/Suggestion: 브라우저 검증은 데모 데이터 기준이며 실제 운영 데이터의 아주 긴 설명은 `overflow-wrap`으로 보호했다.
- 남은 부채: 표 외의 복잡한 달력·모달 전반에 대한 화면 폭별 전수 검사는 별도 범위다.
