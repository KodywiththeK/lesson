# 기능 명세

이 문서는 첨부 PDF를 바탕으로 정리한 기능 명세다. PDF는 요구사항 자료이며, 제품 방향과 우선순위는 사용자의 최신 지시를 따른다. “확인 필요”로 표시된 항목은 사용자 확인 전 최종 정책으로 구현하지 않는다.

## 공통 목록 동작

- 같은 목록은 데스크톱(1024px 이상)에서 표, 태블릿(768~1023px)에서 행 중심 세미테이블, 모바일(767px 이하)에서 카드로 표시한다. 480px 이하에서는 한 줄 1~2개, 481~767px에서는 2~3개를 정보량에 맞춰 배치하며 어떤 폭에서도 필드·상태·작업 버튼을 생략하지 않는다.

- 목록은 기본 10개를 우선 표시한다.
- 관리 표(원생, 선생님, 거래처, 휴원/퇴원, 회차권, 교재 구매, 입출금 내역, 학원 레슨수입, 교재내역, 선생님 월급, 월별 개인레슨 표)는 하단에 총 건수, 페이지 번호 이동(이전/다음 포함), 페이지당 10·20·30개 선택을 **항상** 보여준다. 결과가 한 페이지뿐이어도 보인다.
- 검색어·필터·페이지 크기를 바꾸면 1페이지로 돌아간다.
- 캘린더 셀, 일별 출석부(전체출석 같은 일괄 처리 대상), 다이얼로그 안 목록, 드롭다운 후보에는 10개 제한을 적용하지 않는다. 드롭다운과 급여 계산은 항상 전체 대상을 쓴다.
- 이름 정렬은 기본적으로 한글 가나다순(숫자는 크기순, 한글, 영문 순)을 따르고, 이름이 같으면 id 같은 보조 기준으로 순서를 고정한다.
- 이름이 없는 시간순 표(입출금 내역, 월별 개인레슨 표)는 날짜·시간순을 기본으로 하고, 같은 시각이면 이름 가나다순이다. 교재 구매·교재내역은 원생명 가나다순 다음에 출고일 순이다.
- 원생, 선생님, 거래처, 교재, 수입 내역은 이름 검색 또는 필터를 제공한다. 휴원/퇴원, 학원 레슨수입, 교재내역, 선생님 월급도 이름 검색을 제공한다.
- 필터 선택지는 현재 페이지가 아니라 전체 데이터(또는 고정 목록)를 기준으로 보여, 필터를 하나 걸어도 다른 값으로 바꿀 수 있다.
- 삭제는 확인 단계(AlertDialog)를 거친다. 퇴원 원생과 퇴사 선생님은 결제·회차권·급여 기록을 보존하기 위해 삭제할 수 없고 보관 상태로 유지한다(삭제 버튼은 비활성이며 이유를 안내한다).
- 오류 메시지는 개발자 문구가 아니라 "무엇이 문제이고 어떻게 하면 되는지"를 한국어로 안내한다.

## 홈 화면과 접근 안내

- 홈은 로그인한 역할이 볼 수 있는 메뉴로 바로 이동하는 바로가기만 보여준다. 가짜 건수나 개발 메모는 보여주지 않는다.
- 로그인하지 않은 상태에서는 홈도 로그인 화면으로 보낸다. 로그인은 되었지만 학원 정보를 불러오지 못하면 로그인 폼 대신 원인과 "다시 시도"를 안내한다.
- 현재 역할에게 숨겨진 메뉴의 주소로 직접 들어오면 목록을 불러오지 않고 "이 화면을 볼 권한이 없습니다" 안내와 홈 링크를 보여준다. 이 안내는 화면 편의이며 실제 보호는 서버 권한(RLS)이 한다.

## 핵심 출결/회차권 규칙

- 수업 일정에 원생이 올라와 있다는 이유만으로 회차권을 차감하지 않는다.
- 실제 등원/출석 확인을 눌렀을 때만 해당 원생, 학원, 악기의 회차권에서 1회를 차감한다.
- 결석은 회차권을 차감하지 않는다.
- 같은 수업 출석 확인이 중복 처리되어도 회차권은 중복 차감되지 않아야 한다.
- 다른 학원 tenant의 회차권, 다른 원생의 회차권, 다른 악기의 회차권은 차감하지 못한다.

## 레슨 시간표

레슨 시간표는 두 가지 모드를 가진다.

- 학원 피아노 레슨표: 정기/그룹 성격의 학원 수업
- 개인레슨표: 원생별 1:1 수업

### 학원 피아노 레슨표

- 원생 관리와 선생님 관리의 데이터를 기반으로 표시한다.
- 원생 등록 시 설정한 학원 수업 요일에 따라 매주 자동으로 시간표에 노출된다.
- 일정 항목은 데스크톱에서 드래그 앤 드롭으로 이동할 수 있다(키보드·모바일은 기존 "일정 이동" 다이얼로그). 이동은 **같은 달 안에서만** 가능하고 해당 월에만 반영되며 원생 기본 요일은 바뀌지 않는다. 사유는 묻지 않는다. 출결이 처리된 일정은 이동할 수 없다. **보강 일정을 옮겨도** 보강 표시와 원래 결석과의 연결이 유지되고(시간 미정 보강은 시간을 바꾸지 않을 때만 미정 표시 유지), 같은 결석은 새 날짜의 보강으로 계속 연결된다.
- 날짜를 선택하면 해당 날짜의 예상 출석 원생을 보여준다.
- 해당 날짜의 일정 삭제는 **사유 입력이 필수**다. 삭제한 일정은 숨겨지고 결석인원에 기록되지 않으며, 출결이 이미 처리된 일정은 먼저 출결을 초기화해야 삭제할 수 있다. 삭제해도 원생 기본 정보는 바뀌지 않는다. **보강 일정을 삭제하면** 그 결석은 보강 없이 결석(패스)으로 처리된 상태가 되어 결석인원에 되살아나지 않고, 월별 포스트잇에 `원생명, 8/12 [수요일] 보강 삭제로 패스 처리` 한 줄이 기록된다.
- **요일별 인원확인**: 달력 위의 접이식 카드가 선택한 달의 정규 일정 기준 월~금 요일별 인원 수·이름과 전체(중복 제외) 인원을 보여준다.
- **출석확인**: 날짜의 명단에서 원생별 등원(O)/결석(X)을 임시로 고르고(전체 등원/전체 결석 일괄 선택 가능) **확인**을 눌러야 한 번에 저장된다. **취소**는 선택을 버린다. 마감 후에도 기존 "출결 초기화"로 수정할 수 있다. 이미 보강·패스로 처리된 결석은 서버가 출결 변경·삭제를 거부한다(다른 관리자의 오래된 화면에서도 "등원"으로 바꿀 수 없다). 결석으로 저장된 원생은 결석인원 목록에 기록되며 이 단계는 결석의 최종 승인이 아니다.
- 월별 메모(메모지)는 날짜별 메모와 별개로, 달마다 하나인 포스트잇이다. 위치·크기를 조절할 수 있고(데스크톱) 새로고침하면 위치·크기는 기본값이지만 내용은 달별로 유지된다. 새 내용이 저장되거나 사유서가 자동 기록되면 "미확인" 표시가 뜨고 "확인" 버튼을 눌러야 해제된다. 선생님 화면에서는 보이지 않는다.
- 선생님은 학원 레슨표를 **조회만** 할 수 있다. 출석·이동·삭제·보강·초기화·일정 추가 버튼은 보이지 않고 조회 전용 안내가 표시된다. (조회 범위는 현재 권한 정책(배정 원생)을 따른다.)

### 결석, 보강, 패스

- 결석인원 목록은 선택 날짜에 결석으로 저장됐고 아직 보강/패스로 처리하지 않은 원생을 보여준다.
- 각 원생은 **결석확인**과 **취소** 액션을 가진다. 취소는 출결을 대기 상태로 되돌린다.
- 결석확인을 누르면 사유서가 열린다. 입력 순서는 ① 사유 선택(필수, 보강/패스) ② 날짜 선택과 보강 시간 ③ 사유 메모(선택)다.
- 보강을 선택하면 보강 날짜는 필수이고 보강 시간은 선택이다. 시간을 비우면 원본 시간으로 저장하되 화면에는 시간을 표시하지 않는다. 패스를 선택하면 날짜·시간 입력은 잠긴다.
- 보강일은 **자동 추천**한다. 후보는 결석일 다음 날부터 14일 이내 월~금 중 그 원생의 정규 등원 요일이 아닌 날이고, 그날 등원 인원이 적은 순(같으면 결석일에 가까운 날)으로 상위 5개를 `8/14 (금) · 3명`처럼 보여주며 1순위를 기본 선택한다. 추천 제목 옆 ⓘ 아이콘의 툴팁이 기준 3가지를 알려주고 달력에서 직접 고를 수도 있다.
- 작성 후 확인하면 "최종확인하시겠습니까?"를 거쳐 처리가 확정되고 결석인원 목록에서 사라진다. 이미 처리된 결석은 새로고침 후에도 다시 처리할 수 없다.
- 보강 확정 시 보강일에 `[보강 수업]` 일정이 생성되고 원본은 결석 기록으로 남는다.
- 학원 레슨은 월 단위 정액이라 보강·패스 모두 회차를 차감하거나 복구하지 않는다.
- 사유서를 확정하면 월별 포스트잇에 한 줄이 자동 기록된다. 보강은 `김동성, 8/14 [금요일] 15:00 보강 - 8/12 [수요일] 사유`(앞 날짜=보강일, 뒤 날짜=결석일, 시간은 입력한 경우만), 패스는 `김동성, 8/12 [수요일] 사유없음`(날짜=결석일, 사유가 있으면 사유)이다.

### 개인레슨표

- 개인레슨표의 날짜를 누르면 출석 확인 다이얼로그가 열리고, 그 안의 "이 날짜에 개인레슨 등록" 버튼으로 그 날짜가 채워진 "레슨 일정 등록" 다이얼로그를 연다. 헤더의 "개인레슨 등록" 버튼도 있다.
- 등록 흐름은 원생 → 악기 → 담당 선생님 → 날짜·시작 시간 순서다. 원생이 없으면 "등록된 원생 없음"을 안내한다.
- 선택 가능한 악기는 해당 원생이 수강 중인 악기로 제한한다. 악기가 하나뿐이면 자동 선택하고 여러 개면 직접 고르게 한다.
- 선생님 선택지는 재직 중이고 `파트`가 악기와 같은 선생님만 가나다순으로 보여주고(해당자가 없으면 전체 재직 선생님과 안내), 악기를 고르면 그 악기의 담당 선생님(없으면 파트가 같은 선생님이 한 명일 때)을 기본으로 선택한다. 담당 선생님은 필수이며 미배정 옵션이 없다.
- **종료 시간은 입력하지 않는다.** 종료 = 시작 시간 + 원생의 레슨 길이이며, 길이는 원생 등록의 요일별 시작·종료 차이에서 가져오고(없으면 30분) 폼에서 수정할 수 있다. 종료 시간은 읽기 전용으로 보여준다.
- 선택한 악기의 사용 가능한 회차권(오늘 유효한 회차권의 잔여 합계)이 없으면 경고로 강조한다. 일정은 등록할 수 있지만 출석 확인 전에 회차권을 등록해야 한다.
- 같은 선생님의 개인레슨과 시간대가 겹치면 시간을 고르는 즉시 경고하고 완료를 막는다(저장 시 서버도 다시 검사한다).
- 선생님 역할에게는 개인레슨 등록 버튼을 보여주지 않는다. 출석 확인은 배정된 원생에 한해 허용한다.
- **등원 확인**을 누르면 해당 학원, 원생, 악기의 회차권을 1회 차감한다. **등원 확인 취소**는 출결 기록을 지우고 차감한 1회를 복구해 예정 상태로 되돌린다. 기존 "결석"은 결석 처리하고 차감된 회차를 복구한다. 출석·결석 상태는 새로고침이나 월 이동 후에도 유지되고, 이미 같은 상태인 버튼은 비활성이다. 안내 문구는 실제 회차권 변화를 말한다.
- 회차는 `현재/총`(예: 5/8)으로 표시한다. 총은 그 원생·악기의 유효 회차권 총 부여 회수, 현재는 **달이 바뀌어도 이어서 센다**: 회차권 유효 기간 안에서 조회한 달 이전에 잡힌(취소 제외) 같은 원생·악기의 레슨 수에 이번 달 순번을 더한다. 결석 레슨도 순번에 포함한다.
- **레슨원생 검색 및 선택**: 원생 이름으로 검색해 원생을 선택하면 잔여 회차, 최근 레슨, 날짜·요일·회차 목록(`8/4 (화) - 1/4`)을 보여주고 **복사**(텍스트를 클립보드에 복사)와 **초기화**(검색어·선택 초기화)를 제공한다. 닫기는 우측 하단 X다. 회차권·레슨이 없는 개인레슨 원생도 검색된다.
- **선생님별 레슨시간표**: 선생님을 선택하면 해당 월의 레슨 일정을 문자·카톡용 텍스트로 만들어 **복사**(녹색)하거나 **초기화**(회색)한다. 닫기는 우측 상단 X다.
- 개인레슨 화면에도 월별 포스트잇이 있다(자동 기록은 학원 레슨표만).

## 회차권

- 개인레슨은 월 고정 수강료가 아니라 **회차권/횟수 기반**으로만 관리한다(월정액 없음).
- 신규 회차권 필드는 원생, 활성 개인레슨 악기, 부여 회수(숫자 직접 입력, 기본 **4회**), **사용 기한(일수, 기본 30)**, 등록일이다. `등록일 + 사용 기한`을 입력 기준 만료일로 미리 보여준다. 결제 금액은 원장에게만 선택 입력으로 보이고, 양수면 같은 저장에서 수입 원장에 기록한다. 데스크는 금액 없이 등록한다.
- 같은 학원·원생·악기에 회차권이 있으면 총 부여·잔여 회수에 새 회수를 더하고 만료일은 기존 만료일과 새 입력 기준 만료일 중 늦은 날로 갱신한다. 등록일은 직전 등록일보다 앞설 수 없다. 각 등록의 회수·실제 유효기간·원래 결제 금액·연결 원장 내역은 별도로 보존한다. 재등록 전 공백 날짜의 수업에는 회차권을 사용할 수 없다.
- 목록은 총 부여, 사용(총 부여−잔여), 잔여, 등록일, 만료일, **서울 기준 남은 일수**, 상태를 표시한다. 만료 당일은 `0일 남음 · 오늘까지 사용 가능`으로 구분하고, 320px 모바일에서는 같은 정보를 한 줄 한 장의 카드로 제공한다.
- 권한 있는 역할(원장·데스크)은 부여 회수, 잔여 회수, 만료일을 수정할 수 있다. 수정 사유는 필수이고 변경 전후가 이력(회차 조정 이력과 감사 로그)으로 남는다. 삭제는 정책이 정해질 때까지 제공하지 않는다.
- 등록 유효 구간에 있는 개인레슨 출석 확인만 1회를 차감한다. 등원 확인 취소 안내는 실제로 차감이 복구된 경우에만 `1회 복구`라고 말한다.
- **잔여 회수가 2회 이하이면 눈에 띄게 강조**한다(잔여 0은 소진). 만료일 기준 강조("만료 임박")는 하지 않으며, 이미 지난 회차권은 "만료" 상태로만 표기한다.
- 선생님은 전체 회차권 관리나 결제 금액을 볼 수 없고, 개인레슨표에서 본인이 담당하는 원생·악기의 잔여 회수와 만료일만 확인한다.
- 학원 레슨수입의 개인레슨 행은 회차권 등록 건마다 별도로 표시한다. 월은 연결 원장의 실제 발생일·금액을 기준으로 하고, 0원 등록은 `0원 등록`, 원래 양수 결제였으나 원장 기록이 없는 건은 `원장 기록 없음`으로 구분한다.

## 인원·거래처 관리

이 영역은 `인원·거래처` 상위 메뉴 안에서 네 가지 하위 관리 화면을 가진다.

- 원생
- 선생님
- 휴원/퇴원
- 거래처

URL 구조는 하위 화면별로 분리한다.

- `/management/students`: 원생 관리
- `/management/teachers`: 선생님 관리
- `/management/status`: 휴원/퇴원 관리
- `/management/vendors`: 거래처 관리

### 원생

원생 기본 필드:

- 이름
- 나이
- 학년
- 학교
- 등록일
- 악기 진도
- 보호자 관계를 포함한 연락처
- 하나 이상의 수강 악기

악기별 설정:

- 담당 선생님
- 수업 형태: 학원 수업 또는 개인레슨
- 수업 요일
- 진도
- 레슨비
- 할인
- 최종 수강료

원생 목록은 이름, 선생님, 악기, 정기 요일 기준 검색/정렬을 지원한다. 원생은 수정, 휴원, 퇴원 처리할 수 있다.

### 가격표와 할인

PDF에는 피아노 학원 수업, 피아노 개인레슨, 바이올린, 첼로, 플루트, 할인 금액 표가 포함되어 있다. 이 금액은 구현 시 seeded reference data 후보로 보존하되, 사용자 확인 없이 금액을 최종 정책으로 고정하지 않는다.

할인:

- 형제 할인: 월 -10,000원
- 두 악기 할인: 월 -10,000원
- 소개 할인: 소개한 해당 월 1회 -10,000원

### 선생님

선생님 기본 필드:

- 이름
- 담당 파트: 피아노, 바이올린, 첼로, 플루트, 원장
- 연락처
- 등록일
- 주민등록번호
- 급여 형태

급여 형태:

- 월급제
- 시급제
- 비율제

비율제 급여는 해당 선생님이 담당한 원생의 레슨 수입과 설정된 학원:선생님 비율을 기준으로 계산한다. 원천징수는 기본 급여의 3.3%로 계산한다. 세부 반올림/절사 정책은 확인 필요다.

### 휴원/퇴원

- 원생 목록에서 휴원 또는 퇴원 목록으로 이동할 수 있다.
- 휴원 목록에서는 재원 처리 또는 퇴원 이동을 할 수 있다.
- 퇴원 목록에서는 재원 처리할 수 있다.
- 퇴원 원생은 복구되지 않으면 30일 후 자동 삭제된다. 실제 삭제 방식은 확인 필요다.
- 휴원, 퇴원, 재원 처리에는 확인 다이얼로그가 필요하다.

### 거래처

거래처 필드:

- 거래처명
- 연락처
- 종류
- 비고

거래처는 등록한 뒤 같은 필드를 수정할 수 있다. 거래처 삭제 방식은 정책 미정이라 아직 제공하지 않는다. 선생님은 거래처 관리에 접근할 수 없다.

## 교재 관리

교재 흐름:

```text
등록 -> 재고 -> 구매 목록 -> 출고 -> 결제 완료
```

- 교재는 제목, 가격, 수량, 입고일로 등록한다.
- 재고 목록은 제목, 가격, 수량, 입고일을 표시한다.
- 구매 목록은 원생, 교재명, 자동 입력된 가격, 출고일을 기록한다.
- 출고 시 재고 수량이 1 감소하고 결제 대기 상태가 된다.
- 결제 완료 시 결제일을 기록하고 판매 확정 내역으로 이동한다.
- 결제 완료 기록은 영구 판매 기록이며 수입 관리에 반영된다.
- 재고가 0이 되어도 재고 기록은 보이도록 유지한다.

## 수입 관리

수입 관리는 기본적으로 원장 전용으로 제안한다. 선생님은 본인 급여 정보만 볼 수 있는 방향을 고려하되, 세부 권한은 확인 필요다.

탭:

- 학원 고정 수입
- 입출입 내역
- 교재 내역
- 선생님 월급
- 전체 수입

학원 고정 수입:

- 원생의 최종 수강료 설정을 기준으로 한다.
- 월별 수납/미납 상태를 기록한다.
- 매월 상태는 미납으로 초기화된다.
- 미납 버튼은 미납 목록에 추가한다.
- 재원/퇴원/수강료 변경이 있으면 월별 기록은 달라져야 한다.
- 월 snapshot 기준은 PDF에 “달 넘어가기 하루 전 00:00”으로 표현되어 있으나, 정확한 경계는 확인 필요다.

입출입 내역:

- 원장 또는 허용된 데스크 직원은 수동 수입/지출을 입력할 수 있다.
- 교재 결제 완료와 급여 지급은 자동 내역을 만든다.
- 입출금 내역을 삭제하기 전에는 확인 단계를 거치며, 자동으로 기록된 내역은 원래 기록과의 연결이 끊어질 수 있음을 안내한다.
- 월 선택은 항상 값이 있어야 하며, 비우면 마지막 월로 되돌린다.

선생님 월급:

- 급여 형태, 기본 금액, 세후 금액, 지급 상태, 관리 액션을 표시한다.
- 지급 처리 시 지출 내역을 생성한다.

전체 수입:

- 수입/지출 ledger가 전체 수입 계산의 source of truth다.
- 그래프는 연도/월 기준으로 전체 악기, 개별 악기, 학원 수입, 지출 비교를 지원한다.
- 화면은 선택한 연도의 연간 수입·지출·순수익 합계와 월별 수입·지출·순수익을 함께 보여주고, 분류별 수입은 수입 내역만 집계한다.
