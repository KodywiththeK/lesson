# 기능 명세

이 문서는 첨부 PDF를 바탕으로 정리한 기능 명세다. PDF는 요구사항 자료이며, 제품 방향과 우선순위는 사용자의 최신 지시를 따른다. “확인 필요”로 표시된 항목은 사용자 확인 전 최종 정책으로 구현하지 않는다.

## 공통 목록 동작

- 같은 목록은 데스크톱(1024px 이상)에서 표, 태블릿(768~1023px)에서 행 중심 세미테이블, 모바일(767px 이하)에서 카드로 표시한다. 480px 이하에서는 한 줄 1~2개, 481~767px에서는 2~3개를 정보량에 맞춰 배치하며 어떤 폭에서도 필드·상태·작업 버튼을 생략하지 않는다.

- 목록은 기본 10개를 우선 표시한다.
- 관리 표(원생, 선생님, 거래처, 휴원/퇴원, 회차권, 교재 구매, 입출금 내역, 학원 레슨수입, 교재내역, 선생님 월급, 월별 개인레슨 표)는 하단에 총 건수, 페이지 번호 이동(이전/다음 포함), 페이지당 10·20·30개 선택을 **항상** 보여준다. 결과가 한 페이지뿐이어도 보인다.
- 검색어·필터·페이지 크기를 바꾸면 1페이지로 돌아간다.
- 캘린더 셀, 일별 출석부(전체출석 같은 일괄 처리 대상), 다이얼로그 안 목록, 드롭다운 후보에는 10개 제한을 적용하지 않는다. 드롭다운과 급여 계산은 항상 전체 대상을 쓴다.
- 이름 정렬은 기본적으로 한글 가나다순(숫자는 크기순, 한글, 영문 순)을 따르고, 이름이 같으면 id 같은 보조 기준으로 순서를 고정한다.
- 이름이 없는 시간순 표(입출금 내역, 월별 개인레슨 표)는 날짜·시간순을 기본으로 하고, 같은 시각이면 이름 가나다순이다. 교재 구매·교재내역은 원생명 가나다순 다음에 출고일 순이다.
- 원생, 선생님, 거래처, 교재, 수입 내역은 이름 검색 또는 필터를 제공한다. 휴원/퇴원, 학원 레슨수입, 교재내역, 선생님 월급도 이름 검색을 제공한다.
- 필터 선택지는 현재 페이지가 아니라 전체 데이터(또는 고정 목록)를 기준으로 보여, 필터를 하나 걸어도 다른 값으로 바꿀 수 있다.
- 삭제는 확인 단계(AlertDialog)를 거친다. 퇴원 원생과 퇴사 선생님은 결제·회차권·급여 기록을 보존하기 위해 삭제할 수 없고 보관 상태로 유지한다(삭제 버튼은 비활성이며 이유를 안내한다).
- 오류 메시지는 개발자 문구가 아니라 "무엇이 문제이고 어떻게 하면 되는지"를 한국어로 안내한다.

## 카카오 인증과 학원 가입(2026-10-26 결정, 2026-10-27 이메일 정책 변경)

- 카카오 OAuth로 로그인하며 카카오계정 이메일은 필수 동의로 수집한다. Supabase Auth는 이메일을 계정 생성·기존 계정 중복 확인에 사용하고, 확인된 동일 이메일의 identity를 기존 계정에 자동 연결할 수 있다. 이메일·닉네임·휴대폰은 **학원 권한 판단**에 사용하지 않는다. 현재 기존 원장 계정의 이메일과 연결할 카카오 이메일은 서로 다르고, 해당 카카오 계정으로 이 프로젝트의 로그인을 완료한 적이 없다. 따라서 기존 원장은 **기존 계정으로 먼저 로그인한 뒤** 카카오 identity를 수동 연결하고, 같은 사용자 ID와 학원 멤버십이 유지됐는지 확인한다. 이메일은 앱의 `profiles`에 별도 복사하거나 연락·마케팅에 사용하지 않는다.
- 기존 이메일·비밀번호 계정은 일반 로그인 화면에서 계속 로그인할 수 있다. Supabase Email provider는 유지하되 이메일 신규 가입은 닫고, 새 계정 가입은 카카오로 진행한다. 기존 원장의 연결 화면에서는 국내 휴대폰을 연락용 프로필에 저장한 뒤 카카오 수동 연결로 기존 사용자 ID에 로그인 수단을 추가한다. 학원·원생·수업 데이터를 새 카카오 계정으로 복사하지 않는다. 로컬 개발용 이메일·비밀번호 자동 입력은 운영 화면에서 사용하지 않는다.
- 계정 하나가 여러 학원에 소속될 수 있고 학원마다 다른 역할을 가질 수 있다. 마지막으로 선택한 활성 학원을 열며, 선택 기록이 없거나 사용할 수 없으면 학원을 선택한다. 학원 전환·로그아웃 시 이전 학원의 조회 캐시를 비운다.
- 신규 원장은 이름·국내 휴대폰·학원명을 입력해 학원과 활성 `owner` 멤버십을 한 번에 만든다. 직원은 이름·휴대폰을 입력하고 7일·1회용 초대 링크나 학원 코드로 신청한다. 신청자는 역할을 고르지 않는다.
- 신청은 `pending`·`approved`·`rejected`·`withdrawn` 이력으로 남는다. 신청자는 대기 건을 철회하고 반려 후 다시 신청할 수 있다. 원장은 앱의 대기 목록에서 `desk` 또는 `teacher`를 지정해 승인한다. 선생님 승인에는 같은 학원의 미연결 재직 인사 기록이 필요하다.
- 직원의 현재 접근 상태는 멤버십의 활성·비활성이 결정한다. 원장은 직원 접근 중지·재활성화와 `desk`↔`teacher` 전환을 할 수 있다. 공동 원장 부여·원장 이전은 제공하지 않는다. 연결된 선생님이 휴직·퇴사하면 멤버십이 즉시 비활성화되고 재직 복귀 후에도 원장이 직접 재활성화해야 한다.
- 초대 원문·학원 코드 원문은 발급 시에만 표시하고 DB에는 해시만 저장한다. 학원 코드 재발급은 이전 코드를 즉시 무효화한다. 발급·사용·만료·취소와 신청 철회는 각각 이력으로 구분한다. 가입 알림은 앱 대기 목록만 사용한다.
- 원생·학부모 계정 가입, 계정 탈퇴, SMS 본인 확인은 이번 범위에서 제외한다. 카카오 계정 분실은 서비스 운영자의 별도 신원 확인 후 수동 복구한다.

## 홈 화면과 접근 안내

- 서비스명은 `마디마디`다. 로그인 전 화면, 데스크톱 사이드바와 모바일 메뉴에 로고를 표시한다. 운영 화면에서는 로고 아래 현재 학원명을 보여 준다. 브라우저 탭·Apple·Android 사이트 아이콘에는 제공된 파일을 사용한다.
- 공개 진입점 `/`의 검색·공유 제목과 설명에 “모든 수업의 마디마다, 더 편리한 음악학원 관리”를 사용하고 제공된 썸네일을 공유 이미지로 사용한다. 로그인 뒤 운영 경로는 검색 결과에서 제외하며 사이트맵에는 `/`만 포함한다.

- 홈은 로그인한 역할이 볼 수 있는 메뉴로 바로 이동하는 바로가기만 보여준다. 가짜 건수나 개발 메모는 보여주지 않는다.
- 로그인하지 않은 상태에서는 홈도 로그인 화면으로 보낸다. 로그인은 되었지만 학원 정보를 불러오지 못하면 로그인 폼 대신 원인과 "다시 시도"를 안내한다.
- 현재 역할에게 숨겨진 메뉴의 주소로 직접 들어오면 목록을 불러오지 않고 "이 화면을 볼 권한이 없습니다" 안내와 홈 링크를 보여준다. 이 안내는 화면 편의이며 실제 보호는 서버 권한(RLS)이 한다.
- 데스크톱 사이드바와 모바일 메뉴는 각각의 내부 스크롤 위치를 같은 브라우저 탭에서 유지한다. 메뉴 이동이나 새로고침, 모바일 메뉴 닫기·재열기 뒤에도 위치를 복원하며 본문 스크롤과 서로 영향을 주지 않는다. 새 탭에서는 처음 위치에서 시작한다.
- 사이드바와 모바일 메뉴의 하위 항목은 처음에는 접혀 있고 현재 하위 페이지가 속한 메뉴만 기본으로 펼쳐진다. 데스크톱·모바일 모두 상위 메뉴의 화살표 버튼을 클릭해 펼치거나 접는다. 호버만으로는 열리지 않는다. 다른 하위 페이지로 이동하면 새로 선택된 메뉴만 기본으로 펼쳐진다.

## 핵심 출결/회차권 규칙

- 수업 일정에 원생이 올라와 있다는 이유만으로 회차권을 차감하지 않는다.
- 실제 등원/출석 확인을 눌렀을 때만 해당 원생, 학원, 악기의 회차권에서 1회를 차감한다.
- 결석은 회차권을 차감하지 않는다.
- 같은 수업 출석 확인이 중복 처리되어도 회차권은 중복 차감되지 않아야 한다.
- 다른 학원 tenant의 회차권, 다른 원생의 회차권, 다른 악기의 회차권은 차감하지 못한다.
- 개인레슨의 예약 가능 회차는 `실제 잔여 회차 − 출결 전 예정 일정 수`다. 결석·취소·삭제·등원 일정은 예약 수에서 제외한다. 등록은 예약 가능 회차만 차지하고 실제 잔여는 등원 확인 때만 줄어든다. 기존 초과 예약은 유지하되 추가 등록은 막는다.

## 레슨 시간표

레슨 시간표는 두 가지 모드를 가진다.

- 학원 피아노 레슨표: 정기/그룹 성격의 학원 수업
- 개인레슨표: 원생별 1:1 수업

### 학원 피아노 레슨표

- 원생 관리와 선생님 관리의 데이터를 기반으로 표시한다.
- 원생 등록 시 설정한 학원 수업 요일에 따라 매주 자동으로 시간표에 노출된다.
- 일정 항목은 데스크톱에서 드래그 앤 드롭으로 이동할 수 있다(키보드·모바일은 "일정 이동" 다이얼로그). 이동은 **같은 달 안에서만** 가능하고 이동창에서 날짜·시간·선택 사유를 확인한 뒤 저장한다. 원생 기본 요일은 바뀌지 않는다. 출결이 처리된 일정은 이동할 수 없다. **보강 일정을 옮겨도** 보강 표시와 원래 결석과의 연결이 유지된다.
- 날짜를 선택하면 해당 날짜의 예상 출석 원생을 보여준다.
- 해당 날짜의 일정 삭제는 **사유 입력이 필수**다. 삭제한 일정은 숨겨지고 결석인원에 기록되지 않으며, 출결이 이미 처리된 일정은 먼저 출결을 초기화해야 삭제할 수 있다. 삭제해도 원생 기본 정보는 바뀌지 않는다. **보강 일정을 삭제하면** 그 결석은 보강 없이 결석(패스)으로 처리된 상태가 되어 결석인원에 되살아나지 않고, 월별 포스트잇에 `원생명, 8/12 [수요일] 보강 삭제로 패스 처리` 한 줄이 기록된다.
- **요일별 인원확인**: 달력 위의 접이식 카드가 선택한 달의 정규 일정 기준 월~금 요일별 인원 수·이름과 전체(중복 제외) 인원을 보여준다.
- **출석확인**: 날짜의 명단에서 원생별 등원(O)/결석(X)을 임시로 고르고(전체 등원/전체 결석 일괄 선택 가능) **출석 저장**을 눌러야 한 번에 저장된다. **닫기**는 저장하지 않은 출석 선택만 버린다. 일정 이동·삭제·출결 초기화는 각각의 작업에서 즉시 저장되므로 닫기로 되돌아가지 않는다. 일정 삭제 확인창의 취소는 창만 닫고 삭제 요청을 보내지 않으며, 삭제 후에도 날짜 모달은 열린 상태를 유지한다. 마감 후에도 "출결 초기화"로 수정할 수 있다. 이미 보강·패스로 처리된 결석은 서버가 출결 변경·삭제를 거부한다(다른 관리자의 오래된 화면에서도 "등원"으로 바꿀 수 없다). 결석으로 저장된 원생은 결석인원 목록에 기록되며 이 단계는 결석의 최종 승인이 아니다.
- 월별 메모(메모지)는 날짜별 메모와 별개로 달마다 하나다. 월별 캘린더뷰의 달력 헤더에서 "오늘로 이동" 바로 옆의 `N월 메모지` 버튼으로 노란 메모지 모양의 다이얼로그를 연다(미확인 메모가 있으면 버튼에 "미확인"을 표시). 일별 테이블뷰에는 월별 메모지 버튼이 없다. 다이얼로그를 닫아도 작성 중인 내용은 남고 달 이동·외부 갱신에도 보존한다. 다른 사용자의 저장본과 충돌하면 저장본과 초안을 비교해 선택한다. 새 내용이 저장되거나 사유서가 자동 기록되면 "미확인" 표시가 뜨고 "확인" 버튼을 눌러야 해제된다. 선생님 화면에서는 보이지 않는다.
- 보기는 `월별 캘린더뷰`와 `일별 테이블뷰` 두 탭이다(학원레슨·개인레슨 공통, 탭 높이 48px). **일별 테이블뷰**는 선택한 하루만 보여 주며 출석 확인 모달의 기능을 모달 없이 모두 제공한다. 날짜 컨트롤은 날짜 선택(date-picker)·이전/다음 날짜·오늘로 이동이고, 바로 옆 `M월 D일 메모지` 버튼은 그 날짜의 날짜별 메모(날짜당 여러 개, 원생·선생님 지정, 수정·삭제)를 메모지 모양 다이얼로그로 연다. 학원레슨은 원생별 O/X를 임시로 고른 뒤 `확인`으로 한꺼번에 저장하고 `취소`로 버리며(전체 등원/결석, 검색·출결 필터, 행별 이동·삭제·초기화 포함), 개인레슨은 행에서 등원 확인·취소·결석을 처리하고 결석 사유 입력은 그 행 아래에 펼친다. 변경 이력은 표 아래 접이식 섹션에서 읽는다(관리 권한이고 서비스에 연결된 경우). 선생님(조회 전용)에게는 메모지·변경 이력·확인/취소를 보여 주지 않는다.
- 학원·개인레슨은 복수 악기 필터를 달력·일별 표·출석창에 적용한다. 필터 전 현재 화면의 악기가 하나 이하면 필터를 숨기고, 선택 중이면 해제할 수 있도록 유지한다. 일정과 숨김 건수 및 출석 저장 대상은 선택한 악기에 한정하며 날짜 메모·공휴일·휴원일은 유지한다.
- 달력은 현재 월로 시작하고 오늘을 강조한다. 결석·패스·취소·이동 전 원본은 기본 달력에서 숨기며, `전체 기록 보기`와 날짜별 출석 창에서 확인한다. 작은 모바일의 날짜 칸에는 긴 수업 문구 대신 건수를 보여 준다. 달력 옆에 선택 날짜 패널은 두지 않는다. 날짜 칸을 누르면 열리는 출석 확인 모달(최소 높이 화면의 60%)에서 그날의 수업과 메모를 보고, 관리 권한이 있고 서비스에 연결된 경우 같은 모달의 "변경 이력" 탭에서 그날의 변경 이력을 읽는다.
- 두 레슨 달력 모두 현재 표시 기준 일정이 4건 이상인 날짜를 350ms 정도 호버하면 날짜 칸 중심에서 사방으로 약 2배 크기의 떠 있는 패널을 부드럽게 연다. 화면 경계에서는 위치를 보정하고 내부 스크롤로 네 번째 이후 일정까지 보여 준다. 확대 패널의 빈 곳이나 일정을 클릭해도 해당 날짜의 출석 확인 창을 연다. 네 번째 이후 일정도 패널에서 끌어 다른 날짜로 옮길 수 있으며, 드래그 중에는 패널이 드롭 대상 날짜를 가리지 않는다. 터치 화면은 날짜 선택 창에서 전체 일정을 본다.
- 숨긴 일정 건수 옆에는 결석·패스·취소 건수와 숨김 기준을 설명한다. 두 레슨표 달력에 대한민국 특별 공휴일 이름과 학원 휴원일 이름을 표시한다. 공휴일은 서버가 한국천문연구원 특일정보 API에서 조회하며 키가 없거나 조회에 실패하면 오류와 재시도를 보여 주고 시간표 사용은 유지한다. 일반 일요일은 공휴일로 표시하지 않는다.
- 원장·데스크는 `설정 → 레슨시간표`에서 악기별 색상과 하루·연속 기간·시작/종료일이 있는 매주 반복 요일 휴원일을 학원 공통으로 지정·수정·해제한다. 공휴일과 학원 휴원일의 정기 수업 제외 여부를 각각 설정하며 기본값은 둘 다 켬이다. 쉬는 날의 미처리 정기 수업만 자동 제외하고 출결 처리 및 수동 변경 일정은 유지한다. 제외 사유가 없어지면 수강 조건이 유효한 자동 제외 일정만 복원한다. 공식 공휴일 자료를 확인하지 못하면 해당 월 신규 정기 배정을 보류하고 기존 일정은 보여 준다. 휴원일에 수동 등록하거나 이동하면 휴원 이름을 보여 주고 별도로 확인해야 저장된다.
- 악기마다 색상 선택 메뉴를 따로 제공하며 8개 색의 실제 표시색을 미리 본다. 색을 선택하면 해당 악기만 저장하고 서로 같은 색을 선택할 수 있다. 저장에 실패하면 기존 색을 유지한다. 저장된 색이 없으면 악기 ID에 따라 기본 색을 정하므로 조회 기간이나 사용자별 목록이 달라도 색이 같다.
- 선생님은 학원 레슨표를 **조회만** 할 수 있다. 출석·이동·삭제·보강·초기화·일정 추가 버튼은 보이지 않고 조회 전용 안내가 표시된다. (조회 범위는 현재 권한 정책(배정 원생)을 따른다.)

### 결석, 보강, 패스

- 결석인원은 **조회 중인 달 전체**의 결석을 날짜·시간순으로 한 번에 보여 준다(다이얼로그 안에서 이전/다음 달로 이동). 한 줄 요약(총 건수·미처리·보강·패스)과 날짜·원생·악기·선생님·사유·처리 여부를 함께 보여 주며, 이미 보강·패스로 처리된 결석도 `보강 완료`/`패스 완료`로 표시한다.
- 아직 처리하지 않은(미처리) 결석만 **결석확인**과 **취소** 액션을 가진다. 취소는 출결을 대기 상태로 되돌린다. 처리된 결석에는 버튼이 없다.
- 결석확인을 누르면 사유서가 열린다. 입력 순서는 ① 사유 선택(필수, 보강/패스) ② 날짜 선택과 보강 시간 ③ 사유 메모(선택)다.
- 보강을 선택하면 보강 날짜는 필수이고 보강 시간은 선택이다. 시간을 비우면 원본 시간으로 저장하되 화면에는 시간을 표시하지 않는다. 패스를 선택하면 날짜·시간 입력은 잠긴다.
- 보강일은 **자동 추천**한다. 후보는 결석일 다음 날부터 14일 이내 월~금 중 그 원생의 정규 등원 요일이 아닌 날이고, 그날 등원 인원이 적은 순(같으면 결석일에 가까운 날)으로 상위 5개를 `8/14 (금) · 3명`처럼 보여주며 1순위를 기본 선택한다. 추천 제목 옆 ⓘ 아이콘의 툴팁이 기준 3가지를 알려주고 달력에서 직접 고를 수도 있다.
- 작성 후 확인하면 "최종확인하시겠습니까?"를 거쳐 처리가 확정되고 결석인원 목록에 `보강 완료`/`패스 완료`로 표시된다. 이미 처리된 결석은 새로고침 후에도 다시 처리할 수 없다.
- 보강 확정 시 보강일에 `[보강 수업]` 일정이 생성되고 원본은 결석 기록으로 남는다.
- 학원 레슨은 월 단위 정액이라 보강·패스 모두 회차를 차감하거나 복구하지 않는다.
- 사유서를 확정하면 월별 포스트잇에 한 줄이 자동 기록된다. 보강은 `김동성, 8/14 [금요일] 15:00 보강 - 8/12 [수요일] 사유`(앞 날짜=보강일, 뒤 날짜=결석일, 시간은 입력한 경우만), 패스는 `김동성, 8/12 [수요일] 사유없음`(날짜=결석일, 사유가 있으면 사유)이다.

### 개인레슨표

- 뷰 탭(캘린더·표 보기)과 같은 줄 오른쪽 끝에 "레슨원생 검색" 버튼이 있다. 헤더의 "결석인원"에서는 **조회 중인 달의 개인레슨 결석**을 보고 결석 취소로 예정 상태에 되돌린다. 사유 없이 저장한 결석은 `-`로 표시한다. 담당 선생님도 본인 수업의 결석을 취소할 수 있다. 취소 후 예약 회차가 초과되면 서버가 거부한다.

- 개인레슨표의 날짜를 누르면 출석 확인 다이얼로그가 열리고, 그 안의 "이 날짜에 개인레슨 등록" 버튼으로 그 날짜가 채워진 "레슨 일정 등록" 다이얼로그를 연다. 헤더의 "개인레슨 등록" 버튼도 있다.
- 등록 흐름은 날짜 → 악기 → 원생 → 담당 선생님 → 시간 순서다. 일반 등록에는 선택 날짜에 유효한 회차권과 예약 가능 회차가 있는 원생만 표시한다. 원장·데스크가 `외상 예정으로 등록`을 명시하고 경고를 확인하면 예약 가능 회차가 없는 원생을 선택할 수 있다. 외상 예정은 회차를 예약하지 않는다.
- 선생님 선택지는 재직 중이고 `파트`가 악기와 같은 선생님만 가나다순으로 보여주고(해당자가 없으면 전체 재직 선생님과 안내), 악기를 고르면 그 악기의 담당 선생님(없으면 파트가 같은 선생님이 한 명일 때)을 기본으로 선택한다. 담당 선생님은 필수이며 미배정 옵션이 없다.
- **종료 시간은 입력하지 않는다.** 종료 = 시작 시간 + 원생 수강 정보에 저장된 회당 수업 길이(30분·40분·60분 또는 직접 입력한 5~240분)다. 종료 시간은 읽기 전용으로 보여주며, 이전 수강 정보에 길이가 없으면 원생 수정에서 먼저 보완하도록 안내한다.
- 원생 선택지에는 `예약 가능 N회 · 실제 잔여 N회`를 이름과 함께 표시하고, 선택 후 예정 예약 수까지 보여 준다. 서버는 날짜별 회차권 유효기간과 권별 한도를 원자적으로 검사하므로 화면 검사를 우회하거나 동시에 등록해도 초과 등록할 수 없다.
- 원장·데스크는 예정 개인레슨의 날짜·시간·선생님을 수정하고 사유 없이 삭제 상태로 숨길 수 있다. 수정·같은 달 안의 드래그 이동 사유는 선택 입력이며 이력에 남는다. 등원·결석 일정은 출결을 먼저 취소해야 수정·삭제·이동할 수 있다.
- 악기별 학원 공통 색상은 원장·데스크가 8개 기본 색 중에서 정한다. 기존 직접 선택 색은 RGB 거리상 가장 가까운 기본 색으로 변환한다. 개인레슨 달력·출석창은 일정 배경에, 일별 표는 **악기 이름 태그**에만 악기 색상을 적용한다. 예정과 등원은 같은 색상 레이어 22%를 흰 바탕에 합성하고, 글자는 같은 계열의 진한 색으로 최소 7:1 대비를 유지한다. 표의 원생 이름은 일반 텍스트로 두고 행 전체에는 악기 색상을 채우지 않는다. 예정·등원·결석은 각각 회색·초록·빨강 상태 태그로 구분하며, 색을 지정하지 않은 기본 태그는 흰색 배경과 테두리를 쓴다.
- 같은 선생님의 개인레슨과 시간대가 겹치면 시간을 고르는 즉시 경고하고 완료를 막는다(저장 시 서버도 다시 검사한다).
- 선생님 역할에게는 개인레슨 등록 버튼을 보여주지 않는다. 출석 확인은 배정된 원생에 한해 허용한다.
- **등원 확인**은 일반 예약의 유효 회차를 1회 차감한다. 외상 예정의 등원은 아직 다른 일정에 예약되지 않은 사용 가능 회차가 있으면 차감하고, 없으면 금액 없는 `미정산 1회`를 기록한다. 외상 예정은 나중에 회차권을 사더라도 예정 상태에서는 그대로 두고 등원할 때 판정한다. 담당 선생님도 배정된 외상 수업의 출석을 처리한다. **등원 확인 취소**는 차감한 회차를 복구하고 다음으로 오래된 미정산 출석에 재배정한다. 이미 환불된 유료분으로 정산한 출석은 취소를 막고 별도 정정을 안내한다. **결석을 누르면 사유를 선택으로 입력**(최대 100자, 개인정보는 적지 않도록 안내)할 수 있고 비우면 `결석 확인`으로 저장한다. 이미 결석인 레슨은 **사유 수정**으로 사유만 다시 저장할 수 있으며 회차권에는 영향이 없다. 선생님(담당 원생)도 같은 화면에서 입력·수정한다. 출석·결석 상태는 새로고침이나 월 이동 후에도 유지되고, 이미 같은 상태인 버튼은 비활성이다. 안내 문구는 실제 회차권 변화를 말한다.
- 새 일정의 회차 표시는 연결된 구매 권의 번호/총 횟수(예: `3/4`)이며 실제 사용 횟수와 구분한다. 새 권을 구매해도 기존 일정의 번호는 바뀌지 않는다. 결석은 당시 권·번호를 유지하고 예약 자리만 돌려준다. 기존에 합쳐졌던 통합권은 분할하지 않고 그 권의 이력을 보존한다.
- **레슨원생 검색 및 선택**: 원생 이름으로 검색해 원생을 선택하면 잔여 회차, 최근 레슨, 날짜·요일·회차 목록(`8/4 (화) - 1/4`)을 보여주고 **복사**(텍스트를 클립보드에 복사)와 **초기화**(검색어·선택 초기화)를 제공한다. 닫기는 우측 하단 X다. 회차권·레슨이 없는 개인레슨 원생도 검색된다.
- **선생님별 레슨시간표**: 선생님을 선택하면 해당 월의 레슨 일정을 문자·카톡용 텍스트로 만들어 **복사**(녹색)하거나 **초기화**(회색)한다. 닫기는 우측 상단 X다.
- 개인레슨 화면에도 월별 포스트잇이 있다(자동 기록은 학원 레슨표만).

## 회차권

- 개인레슨은 월 고정 수강료가 아니라 **회차권/횟수 기반**으로만 관리한다(월정액 없음).
- 신규 회차권은 활성 개인레슨 **악기를 먼저 고른 뒤 해당 원생을 선택**한다. 부여 회수는 숫자 직접 입력(기본 **4회**), 사용 기한은 일수 입력(기본 30일), 등록일을 입력한다. `등록일 + 사용 기한`을 입력 기준 만료일로 미리 보여준다. 일반 등록은 양수 결제 금액이 필수이며 같은 저장에서 수입 원장에 기록한다. 원장·데스크가 `서비스로 지급하기`를 고르면 결제 입력 없이 0원으로 등록하고 수입 원장은 만들지 않는다. 기존 0원 등록 이력은 서비스로 분류한다.
- 새 구매는 같은 학원·원생·악기의 기존 권이 있어도 **별도 회차권·등록 이력·목록 행**으로 만든다. 기존 `3/4`와 새 `0/4`를 따로 표시한다. 등록일은 직전 구매일보다 앞설 수 없다. 기존에 합쳐진 권은 통합권으로 보존한다. 재등록 전 공백 날짜의 정상 예약·출석에는 새 권을 사용할 수 없다.
- 목록은 총 부여, 사용(총 부여−잔여), **유료·서비스별 잔여와 미정산 횟수**, 등록일, 만료일, **서울 기준 남은 일수**, 상태를 표시한다. 개인레슨표에도 미정산 횟수를 표시한다. 만료 당일은 `0일 남음 · 오늘까지 사용 가능`으로 구분하고, 320px 모바일에서는 같은 정보를 한 줄 한 장의 카드로 제공한다.
- 권한 있는 역할(원장·데스크)은 부여 회수, 잔여 회수, 만료일을 수정할 수 있다. 수정 사유는 필수이고 변경 전후가 이력(회차 조정 이력과 감사 로그)으로 남는다. 수정·삭제로 기존 예정 예약을 초과하게 만들 수 없다.
- 정상 예약·출석은 연결된 권의 등록 유효 구간을 지킨다. 예약과 실제 차감 모두 사용 가능한 서비스권을 우선하고 같은 종류에서는 오래된 유효권을 우선한다. 일정 이동은 이미 연결된 권의 유효기간 밖이면 거부한다. 새 회차권 등록 시 미정산 출석을 수업 날짜가 오래된 순서대로 정산하고, 부족하면 나머지는 미정산으로 남긴다. 과거 출석의 정산에는 새 회차권의 등록일·만료일을 적용하지 않는다. 기존 출석·사용 이력만으로 과거 미정산을 추측해 생성하지 않는다.
- 회차권 수정·환불은 유료 횟수와 결제액에만 적용한다. 미사용 서비스 횟수는 원장·데스크의 별도 회수와 감사 이력으로 정정하고, 예약 한도를 깨면 거부한다. 유료분 환불 뒤에도 서비스 잔여와 이미 완료된 외상 정산 이력은 유지한다.
- **잔여 회수가 2회 이하이면 눈에 띄게 강조**한다(잔여 0은 소진). 만료일 기준 강조("만료 임박")는 하지 않으며, 이미 지난 회차권은 "만료" 상태로만 표기한다.
- 회차권 목록의 상태 탭은 기본 `사용중`, `사용완료`, `사용취소`로 구분한다. 사용중에서는 전체·정상·잔여 부족을 고르고, 소진 또는 만료는 사용완료에서 본다. 삭제·환불은 사용취소 이력으로 보존하며 과거 감사 이력의 없는 값은 `알 수 없음`으로 표시한다. 서비스가 남은 부분 환불은 남은 권과 유료분 환불 이력을 각각 표시한다.
- **삭제(2026-10-22)**: 목록 행의 삭제 버튼(원장·데스크)은 확인창을 열고 두 방식 중 고른다. 확인창은 서버가 계산한 미리보기(현재 환불 규정, 사용 N/M회, 환불 예정 금액)를 보여 준다.
  - **환불 처리(기본)**: 학원 환불 규정을 검사한다. 맞으면 회차권을 지우고 **연결된 수입 행 금액을 환불액만큼 줄인다**(가장 최근 결제부터, 0원이 되면 행 삭제). 환불액은 결제 합계 × 남은 회수 ÷ 부여 회수를 원 단위로 반올림한다. 맞지 않거나 돌려줄 금액이 없으면 회차권만 삭제되고 수입 내역은 그대로 남는다.
  - **잘못 등록해서 삭제**: 한 번도 쓰지 않은(잔여가 줄지 않고 사용 기록이 없는) 회차권만 가능하다. 회차권과 연결된 수입 기록을 함께 지운다. 사용한 회차권은 선택할 수 없고 이유를 안내한다.
  - 회차권을 지우면 등록 이력·수동 조정·사용 이력도 함께 사라지며, 이미 확정된 출석 기록은 그대로 남는다. 삭제 이력은 감사 기록(`lesson_ticket.deleted`)에 방식·규정·환불액과 함께 남는다.
- **환불 규정(학원 설정)**: 설정 메뉴(원장 전용)의 `회차권 설정`에서 세 가지 중 하나를 고른다. ① 언제든 남은 회수 비례 환불 ② 반 이하 사용 시에만 남은 회수 비례 환불(사용 횟수 × 2가 부여 회수 이하일 때) ③ 환불 불가. 설정하지 않은 학원은 ③이다. 설정 메뉴는 이번에 회차권 환불 규정만 담고, 다른 학원 단위 설정이 생기면 같은 곳(`academy_settings`)에 더한다.
- 선생님은 전체 회차권 관리나 결제 금액을 볼 수 없고, 개인레슨표에서 본인이 담당하는 원생·악기의 잔여 회수와 만료일만 확인한다.
- 학원 레슨수입의 개인레슨 행은 회차권 등록 건마다 별도로 표시한다. 월은 연결 원장의 실제 발생일·금액을 기준으로 하고, 0원 등록은 `0원 등록`, 원래 양수 결제였으나 원장 기록이 없는 건은 `원장 기록 없음`으로 구분한다.

## 인원·거래처 관리

이 영역은 `인원·거래처` 상위 메뉴 안에서 다섯 가지 하위 관리 화면을 가진다.

- 원생
- 선생님
- 휴원/퇴원
- 거래처
- 상담

URL 구조는 하위 화면별로 분리한다.

- `/management/students`: 원생 관리
- `/management/teachers`: 선생님 관리
- `/management/status`: 휴원/퇴원 관리
- `/management/vendors`: 거래처 관리
- `/management/consultations`: 상담 관리 (원장·데스크만)

### 원생

원생 기본 필드:

- 이름
- 나이·출생연도(둘 다 선택이며 한쪽을 입력하면 현재 연도 기준 한국식 나이를 서로 계산)
- 학년
- 학교
- 등록일
- 악기 진도
- 보호자 관계를 포함한 연락처
- 하나 이상의 수강 악기

악기별 설정:

- 담당 선생님
- 수업 형태: 학원 수업 또는 개인레슨
- 수업 요일
- 진도
- 레슨비
- 할인
- 최종 수강료
- 개인레슨 월 횟수와 회당 수업 길이(30분·40분·60분 또는 직접 입력한 5~240분), 요일별 시작 시간

원생 목록은 이름, 선생님, 악기, 정기 요일 기준 검색/정렬을 지원한다. 수정·상태 변경 직후에는 저장한 값이 바로 보이고, 이후 목록을 다시 불러와 서버 값이 달라지면(다른 사용자의 변경 등) 서버 값이 우선한다. 검색·필터 3개·정렬 2개·초기화는 어떤 화면 폭에서도 카드 안에 들어오게 반응형 격자(좁으면 2열, 넓으면 3열, 아주 넓으면 한 줄)로 배치한다. 원생은 수정, 휴원, 퇴원 처리할 수 있다.

- 같은 이름의 원생은 직원이 `홍길동a`, `홍길동b`처럼 직접 구분해 입력한다. 같은 이름이 이미 있으면 등록할 때 경고만 보이고 저장은 막지 않는다.
- 나이와 출생연도는 `현재연도 - 출생연도 + 1`로 양방향 계산한다. 한쪽을 비우면 둘 다 비워 개인정보를 제거한다. 나이 1~7세에는 `유치원생(미취학아동)`, 8~19세에는 초1~고3 학년을 제안하되 사용자가 고친 학년을 덮어쓰지 않는다. 저장된 학년은 매년 진급하고 미취학은 8세에 초1, 고3은 다음 해에 빈 값이 된다. 변환할 수 없는 기존 학년 문구는 보존한다. 20세 미만의 직업 기본값은 `학생`이며 수정할 수 있다.
- 두 번째 연락처는 관계와 전화번호를 함께 입력하는 선택 항목이다. 둘 다 비우면 저장하지 않으며, 수정에서 둘 다 비우면 기존 두 번째 연락처를 삭제한다. 하나만 입력하면 해당 필드 옆에 오류를 표시한다.
- 수강 요일은 월~토에서 고른다. 이전에 일요일로 저장된 요일은 계속 표시하고 수정할 수 있다.
- 수정 화면은 등록 화면과 같은 필드(이름, 등록일, 나이·출생연도, 학년, 학교, 직업, 연락처, 담당 선생님, 수업 형태, 요일별 시간, 개인레슨 월 횟수·수업 길이, 진도, 레슨비, 할인)를 바꿀 수 있다. 복수 악기 원생은 활성 악기마다 섹션이 나뉘어 모든 악기의 담당 선생님·수업 형태·요일별 시간·개인레슨 설정·진도·레슨비·할인을 수정할 수 있다.
- **악기 추가**: 수정 화면에서 새 악기를 추가한다(등록 화면과 같은 악기·담당 선생님·수업 형태·요일별 시간·진도·레슨비·할인 입력, **수강 시작일은 기본 오늘**). 이미 수강 중인 악기·수업 형태 조합은 고를 수 없다. 시작일 이후의 정기 일정이 생기고 월 수강료는 시작일이 속한 달부터 만들어진다.
- **수강 종료(악기 삭제)**: 악기마다 [수강 종료]가 있고 확인 창을 거친다. 수강 정보를 지우지 않고 종료 처리하며, 정기 레슨 시리즈가 닫히고 오늘 이후 출석 기록이 없는 정기 일정만 취소된다. 이동·보강·수동·개인레슨 예정 일정은 남고 저장 후 남은 건수를 안내한다(정리는 레슨표에서 한다). 이미 만들어진 월 수강료 기록·회차권 잔액·과거 일정은 바뀌지 않는다. 종료한 악기는 월 수강료가 종료일이 속한 달까지만 만들어지고 원생 목록·상세에는 보이지 않는다. 같은 악기·수업 형태를 다시 추가하면 **새 수강 기록이 따로 생기고** 종료한 수강의 기록(월 수강료·일정·이력)은 그대로 남는다(다시 시작하는 날짜는 종료일 다음 날부터 가능하다). 월 수강료는 수강 기간마다 따로 만들어져 예전 기간의 수강료가 빠지지 않는다. 같은 달 안에서 종료하고 다시 추가하면 그 달의 월 수강료는 늦게 시작한 수강 기준 한 건이다. **마지막 활성 악기는 종료할 수 없다**(모두 종료하려면 휴원·퇴원 처리).
- **수업 형태 변경**: 기존 수강의 수업 형태(학원레슨·개인레슨)는 등록과 같은 정책을 따른다. 피아노만 학원레슨·개인레슨을 둘 다 고를 수 있고 나머지 악기는 개인레슨 전용이며, 이미 저장된 현재 값은 이전 데이터라도 계속 선택할 수 있다. 같은 악기를 이미 그 형태로 수강 중이면(저장 후 모습 기준, 종료 예정 수강 포함) 그 형태는 선택할 수 없고 이유가 보인다. 수업 형태를 바꾸면 이전에 직접 입력한 레슨비를 이어 쓰지 않고 새 형태의 진도·요일·월 횟수·수업 길이에 맞는 가격표 금액으로 초기화한다.
- **악기 이름 변경**은 제자리 변경이 아니라 **종료 + 추가**로 교체한다. 악기 코드는 월 수강료·회차권·급여의 기준이라 기존 수강의 악기 칸은 읽기 전용이다.
- **저장은 한 번에 처리(원자 저장)**: 이름·기본 정보·악기 수정·추가·종료를 한 번의 서버 호출(한 트랜잭션)로 저장한다. 어느 한 곳이라도 실패하면 아무것도 저장되지 않고 폼은 입력값을 유지한 채 열려 있다.
- 학원 수업의 담당 선생님과 수강 요일은 필수다. 요일별 시작·종료 시간은 함께 입력하거나 함께 비워야 한다. 시간이 비어 있어도 해당 요일에 `시간 미정` 반복 일정이 생성되고 실제 시간을 입력하지 않아도 출석 처리할 수 있다. 시급제 급여는 출근 일정 기준, 비율제 급여는 완료 수업 횟수 기준을 유지한다. 수정 화면에서 담당 선생님은 악기 파트가 같은 선생님을 보여 주고, 기존 담당 선생님이 휴직·퇴사로 목록에 없어도 조용히 다른 선생님으로 바뀌지 않는다.
- 개인레슨은 주 1일이면 월 4회, 주 2일이면 월 8회로 정하고 주 3일 이상이면 월 횟수를 직접 입력한다. 회당 수업 길이는 30분·40분·60분 또는 직접 입력한 5~240분 정수 중 고르며 요일별 시작 시간은 선택이다. 시작 시간을 입력하면 종료 시간은 자동 계산되고 직접 수정할 수 없다. 이전 개인레슨에 월 횟수나 수업 길이가 없으면 임의 기본값으로 저장하지 않고 수정 화면에서 보완하도록 안내한다.
- 레슨표에서 개인레슨 일정 한 건을 등록할 때는 원생 수강 정보의 월 횟수를 참고 정보로 보여 주고, 저장된 회당 수업 길이로 종료 시간을 계산한다. 이 화면에서 월 횟수만큼 일정을 한꺼번에 만들지는 않는다.
- 원생 상세는 활성 수강 악기의 할인 전 월 합계, 매월 할인 합계, 최종 월 수강료를 함께 보여 준다. 한 번만 적용되는 지인 소개 할인은 매월 할인 합계에서 제외한다.
- 선생님 계정이 원생 화면을 열면 담당 원생의 이름·악기·정기 요일만 읽기 전용으로 보인다(등록·수정·휴원·퇴원 버튼, 학교·나이·수강료·연락처 없음).

### 가격표와 할인

레슨비는 아래 가격표에서 자동으로 정하고(코드 상수), 진도는 수업 형태별 선택 목록에서 고른다. 최종 수강료는 레슨비에서 매달 적용 할인을 뺀 금액이다.

- 피아노 학원 수업: 수강 요일 개수로 구간이 정해진다(2개 = 주 2회, 3개 = 주 3회, 4~5개 = 주 4·5회). 요일 1개 또는 6개처럼 가격표에 없는 구간은 자동 계산을 끄고 레슨비를 직접 입력하게 안내한다.
- 피아노 개인레슨, 바이올린, 첼로, 플루트: 진도와 월 횟수(4/8회), 레슨 길이(40/60분)일 때만 가격표로 레슨비를 자동 계산한다. 30분과 직접 입력한 길이는 레슨비를 수동 입력한다.
- 체르니100 레슨비는 주 2회 150,000원, 주 3회 160,000원, 주 4·5회 170,000원이다.
- 가격표로 계산된 금액도 직접 수정할 수 있다. 직접 입력한 금액은 진도·요일·시간을 바꿔도 유지하고 `가격표로 재계산`을 눌렀을 때만 현재 가격표 금액으로 바뀐다.

할인(각 -10,000원, 복수 선택 가능):

- 두 자녀 할인: 매달
- 두 악기 할인: 매달
- 지인 소개 할인: 소개한 달에만. 원생 할인 수정 시 현재 월의 미입금·미납 기록과 변경된 소개 적용 월의 미입금·미납 기록에 반영한다. 기록 당시 할인 구성을 알 수 없는 기존 기록은 자동으로 바꾸지 않고 확인을 안내하며 입금 완료 기록은 유지한다.

### 선생님

선생님 기본 필드:

- 이름
- 담당 파트: 피아노, 바이올린, 첼로, 플루트, 원장
- 연락처
- 계약 시작일·종료일(선택)
- 주민등록번호
- 급여 형태

급여 형태:

- 월급제
- 시급제
- 비율제

등록일은 신규 등록 시 서울 기준 오늘로 자동 저장하고 수정하지 않는다. 목록에는 등록일 대신 계약 기간을 `시작일~종료일`, `시작일~`, `~종료일`, `-`로 표시한다. 급여 설정(급여 형태·금액·비율)은 원장만 다룬다. 데스크는 선생님의 기본 정보(이름, 파트, 연락처, 계약 기간(선택), 출근 요일·시간)만 등록·수정하며 급여 칸을 보지 못한다.

- 담당 파트는 선택 목록(피아노, 바이올린, 첼로, 플루트, 원장)에서 고른다. 목록 밖 값이 이미 저장되어 있으면 그대로 보여 준다.
- 시급제 급여는 `시급 × 선생님 출근 요일·시간 기준 그 달 근무 시간 합계`(분 단위 합계로 계산한 뒤 시급 × 분 ÷ 60을 내림)이다. 계약 시작·종료일이 있으면 그 밖의 날짜는 제외하고, 계약기간을 입력하지 않았으면 그 달 전체를 대상으로 한다.
- 비율제 급여는 해당 선생님이 담당한 원생의 레슨 수입과 설정된 학원:선생님 비율을 기준으로 그 달 등원 확인 횟수만큼 계산한다. 원천징수는 기본 급여의 3.3%로 계산하고 소수점은 내린다.
- 비율제의 학원 몫·선생님 몫은 0~10 정수로 입력하며 한쪽을 바꾸면 다른 쪽을 자동으로 `10 - 입력값`으로 맞춘다. 출근 요일은 저장 순서와 관계없이 월·화·수·목·금·토·일 순으로 표시한다.
- 주민등록번호는 입력할 때 형식(13자리, 생년월일 유효)을 검사하고 암호화해 저장한다. 목록과 상세에는 항상 `900101-1******`처럼 마스킹해 보여 주고, 원문은 원장만 확인 창을 거쳐 볼 수 있으며 열람 기록이 남는다.

### 휴원/퇴원

- 원생 목록에서 휴원 또는 퇴원 목록으로 이동할 수 있다.
- 휴원 목록에서는 재원 처리 또는 퇴원 이동을 할 수 있다.
- 퇴원 목록에서는 재원 처리할 수 있다.
- 퇴원 목록에서는 휴원 처리도 할 수 있다(휴원 ↔ 퇴원 전환 모두 허용).
- 퇴원 원생은 복구되지 않으면 30일 후 자동으로 보관 처리(`archived_at`)되어 목록에서 사라진다. 데이터를 지우지는 않으며, 실제 삭제 방식과 복구 화면은 확인 필요다.
- 재원 처리하면 휴원·퇴원 때 닫은 정기 레슨 일정이 복귀일부터 다시 만들어진다(복귀일 이전에 취소한 일정은 되살리지 않는다). 같은 상태로 다시 처리하면 거부한다.
- 휴원, 퇴원, 재원 처리에는 확인 다이얼로그가 필요하다. 처리 시각은 서버 시각으로 기록한다.
- 퇴원 원생·퇴사 선생님의 상세에는 비활성 삭제 버튼과 보관 안내가 보인다.

### 거래처

거래처 필드:

- 거래처명
- 연락처
- 종류
- 비고

거래처는 등록한 뒤 같은 필드를 수정할 수 있다. 원장·데스크는 목록에서 확인 후 거래처를 삭제할 수 있다(되돌릴 수 없다). 교재 발주 내역에는 거래처 이름이 남고 거래처와의 연결만 끊긴다. 선생님은 거래처 관리에 접근할 수 없다.

### 상담

전화·문자로 상담한 인원을 기록해 두는 화면이다. 원장·데스크만 접근하며 선생님은 메뉴와 직접 주소 모두 막힌다.

- 입력: 이름(필수), 나이, 악기(복수 선택), 전화번호(필수), 학교, 특이사항(메모). 접수일은 등록 시점으로 자동 기록된다.
- 목록: 이름·학교·전화·악기·특이사항 검색, 악기 필터, 접수일 최신순, 페이지 이동. 각 행에서 `원생 등록`, `수정`, `삭제`를 할 수 있다.
- `원생 등록`을 누르면 원생 등록 창이 상담의 이름·나이·학교·전화번호·악기로 미리 채워져 열린다. 담당 선생님, 수업 형태, 요일, 레슨비, 등록일은 직접 입력한다. 등록에 성공하면 그 상담 기록은 자동으로 삭제된다. 등록은 성공했는데 상담 삭제가 실패하면 상담이 남고 직접 삭제하라는 안내가 나온다. 특이사항은 원생 정보로 넘어가지 않는다.
- `삭제`는 확인 창을 거친 뒤 바로 지운다.
- 개인정보 보관: 접수 시각으로부터 1년이 지난 상담 기록은 목록에서 보이지 않고 매일 새벽 자동으로 삭제된다.

## 교재 관리

상세 명세는 `docs/product/book-management-spec.md`에 있다. 요약:

교재 흐름:

```text
교재 등록(입고) → 재고 → 출고 등록 시 결제 대기 또는 결제 완료 선택(원장). 결제 대기 건은 나중에 완료로 전환하지 않는다.
```

- 메뉴 "교재" 아래 하위 탭 4개: 재고(`/books`), 출고(`/books/shipments`), 결제 완료(`/books/paid`), 발주·입고(`/books/orders`). 원장·데스크만 접근한다.
- 발주·입고에서는 거래처별 발주일, 품목, 수량, 매입가를 기록한다. 전량 입고를 한 번 확정하면 재고가 증가하고, 새 도서는 입고할 때 판매가를 정한다. 원장은 입고 전에도 발주 금액을 지급일과 함께 원장 지출로 확정할 수 있다. 지급·입고·발주 취소는 상태에 따라 되돌리며 이미 출고된 재고를 안전하게 되돌릴 수 없으면 취소를 막는다.
- 교재는 도서명, 가격, 권수, 입고일, 구입 거래처명(선택, 자유 텍스트)으로 등록한다. 교재 한 줄이 현재 재고 권수 하나를 가지며 입고 이력은 따로 남기지 않는다. 같은 도서명을 다시 등록하면 기존 교재에 권수가 합산되고 입고일은 최근 입고일로 바뀐다. 구입 거래처명은 재입고에서 입력하면 덮어쓰고 비우면 기존 값을 유지하며, 수정에서는 비우면 지워진다.
- 재고 표는 도서명·가격·권수·입고일을 보이고 도서명 검색과 오름/내림 정렬, 수정·삭제를 제공한다. 권수가 0이어도 목록에 남고 "재고 없음"으로 표시된다. 삭제는 보관 처리라 판매 기록은 도서명·가격 스냅샷으로 그대로 남는다.
- 출고 등록은 재원 원생, 도서(가격 자동 입력, 출고 자리에서 수정 가능), 수량, 출고일을 입력한다. 재고가 수량만큼 줄고 재고가 모자라면 막는다. 한 건의 금액은 단가 × 수량이다. 원장은 출고 등록에서 바로 결제 완료(입금일 칸)를 고를 수 있다.
- 출고목록(결제 대기)은 원장·데스크가 수정·삭제할 수 있고, 수정·삭제 때 재고는 한 번에 복원·재차감된다.
- 입금 확인은 원장이 출고를 등록할 때만 선택한다. 입금일은 출고일 이후여야 하고(미래 허용), 출고·재고 차감·입출입내역 수입 행(금액 = 단가 × 수량)을 한 작업에서 기록한다.
- 결제 완료 기록은 수정·삭제할 수 없다. 원장만 사유를 적어 결제를 취소하면 대기로 돌아가고 입출입내역 수입 행이 삭제되며 감사 기록이 남는다(재고는 바뀌지 않음).
- 원생이 삭제되어도 판매 기록은 이름 스냅샷으로 보존된다. 교재·출고 데이터는 브라우저에서 직접 쓰지 못하고 서버 RPC로만 바뀐다.

## 수입 관리

수입 관리는 **원장 전용**이다(데스크·선생님은 메뉴와 직접 주소 모두 막힌다). 선생님 본인 급여 조회와 데스크의 입출입내역 입력은 후속 질문이다(`open-questions.md`). 모든 집계는 월 단위이며 같은 달 기준이다. 모든 금액은 사업자 통장으로 통일되므로 **입출입내역이 곧 전체 수입**이고, 고정 수입·교재 내역·선생님 월급은 같은 내용을 보기 쉽게 모은 화면이다(이중 집계 금지).

탭(왼쪽부터, 기본은 첫 탭): 학원 고정 수입 → 입출입내역 → 교재 내역 → 선생님 월급 → 전체 수입. 메뉴 이름은 "수입 관리"다. 조회 월은 탭을 옮겨도 이어지고(새로고침하면 이번 달), 이번 달보다 뒤의 달은 고를 수 없다. 금액 색은 합계 파랑·수입 초록·지출 빨강이다.

학원 고정 수입 (원생 레슨 수입):

- 원생관리의 악기별 설정(레슨비·할인·최종금액·진도)을 월별로 기록한다. 합계는 "전체 금액 합산"(개인레슨 회차권 등록 건 포함)이다.
- 입금 상태는 3가지다: **미입금**(매달 모든 원생의 기본), **입금 완료**, **미납**. 원생별 "입금"·"미납"·"입금 취소"·"미납 해제" 동작이 있고 입금하면 입금일(기본 오늘)과 함께 입출입내역에 수입이 같은 시점에 기록된다. 입금 취소는 확인을 거쳐 연결된 입출입내역을 삭제하고 미입금으로 되돌린다. 결제 금액이 0원인 항목은 입금할 수 없다.
- "미납 해제"는 미납 상태일 때만, "입금 취소"는 입금 완료일 때만 처리된다(오래된 화면에서 다른 상태의 항목을 되돌릴 수 없다).
- "미납 인원 N명" 버튼은 **미납을 누른 원생만** 보여 주고 입금하면 자동으로 빠진다. 월말 자동 전환은 없다.
- 입금일이 보고 있는 월 밖이면 어느 월 입출입내역으로 기록되는지 안내한다. 월 마감 잠금은 없어 원장은 지난달도 수정할 수 있다.
- 입금 완료인데 입출입내역 행이 사라진 항목은 "원장 기록 없음"으로 표시한다.
- 입금할 때 카드(지역화폐 포함)·현금·계좌이체·비대면결제 중 한 방식을 필수로 선택한다. 기존 입금의 방식은 미기록으로 표시하며 입금 취소 시 방식도 지운다. 입금과 원장은 같은 트랜잭션으로 저장한다.
- 월 기록은 처음 조회할 때 생성한다. 이후 할인 변경은 확인 가능한 현재 월 미입금·미납 기록과 소개 적용 월에만 반영하며 입금 완료와 다른 월의 일반 할인은 유지한다. 퇴원·휴원 원생의 미입금 기록 정리는 후속 질문이다.

입출입내역:

- 월 선택과 함께 "월별 총 수입(입금)"(초록)·"월별 총 출금"(빨강) 카드를 보여 준다. 합계는 검색·필터와 무관하게 그 월 전체 기준이다.
- 원장은 수동 입금/출금을 날짜(기본 오늘)·유형·분류·내용·금액으로 등록·수정·삭제한다. 분류는 유형에 맞는 것만 고르며 상한은 20억 원 미만이다.
- 수강료 입금, 교재 결제 완료, 급여 지급은 자동 내역을 만든다. 자동 내역도 금액·날짜·설명은 수정·삭제할 수 있지만 유형과 출처는 바꿀 수 없고, 원천(고정 수입·교재·급여)에는 반영되지 않는다. 삭제 전에는 확인 단계를 거치며 원래 화면에서 되돌리는 방법을 안내한다.
- 검색·유형만 기본 필터이고 출처·분류·기간·정렬은 "상세 필터"에 접혀 있다. 월 선택은 항상 값이 있어야 한다(비우면 마지막 월로 되돌린다).

교재 내역:

- 교재 관리에서 **결제 완료**된 건만 입금일이 속한 월 기준으로 보여 주는 조회 전용 화면이다. 같은 원생·출고일의 품목은 한 행으로 묶어 펼쳐 본다. 입금 완료인데 입출입내역 행이 사라진 건은 "원장 기록 없음"으로 표시한다. 월 수입·발주 지급·차액은 실제 원장 입출금일 기준으로 계산하며, 발주·입고·지급일도 함께 조회한다. 연결 원장이 수정·삭제되면 불일치를 알린다.
- 결제 대기 건은 나중에 완료로 전환할 수 없다. 결제를 취소한 건을 다시 확정하려면 출고를 삭제하고 새로 등록한다(결제 취소는 원장만 교재 관리의 결제 완료 탭에서 한다).

선생님 월급:

- 월 선택과 함께 선생님별 담당 파트, 급여 형태·설정, 기본 급여(세전), 원천징수(3.3%), 최종 지급액(세후), 산출 근거, 지급 상태를 보여 준다. 합계는 "지급 예정 급여"와 "지급 완료 급여"로 나눈다.
- 급여 행은 그 달에 정산(지급 완료·미지급) 기록이나 등원 확인된 수업이 있는 선생님이면 퇴사·휴직이어도 보여 주고, 기록이 없으면 재직 중이면서 입사(계약 시작)한 달 이후일 때만 만든다(입사 전 달 월급 행과 기록 없는 퇴사자 행은 만들지 않는다).
- 월급제는 설정 금액, 시급제는 시급 × 선생님 **출근 요일·시간 기준 그 달 근무 시간 합계**(계약 시작·종료일이 있으면 그 안의 날짜만, 없으면 그 달 전체, 분 단위 합계로 계산한 뒤 `floor(시급 × 분 ÷ 60)`, 등원 확인 수업과 무관), 비율제는 **1회 레슨비 × 선생님 비율 × 등원 확인 횟수**다. 학원 레슨 1회 레슨비는 월 최종 수강료(그 달 월 snapshot 금액 우선, 없으면 현재 금액) ÷ 그 달 **정규·이동 예정 수업 수**(취소·보강·수동·특별 수업 제외, 등원이 예정보다 많으면 분모를 등원 횟수로 맞춰 월 수강료를 넘지 않게 함)이고, 같은 원생·악기를 여러 선생님이 나눠 가르쳐도 분모는 원생·악기 단위로 한 번만 센다. 개인레슨은 회차권 결제 금액 ÷ 부여 회수이며 여러 원생은 원생별로 계산해 합산한다. 학원 레슨의 월 수강료나 개인레슨의 결제 금액을 찾지 못하면 그 건수를 안내한다. 예: 140,000원 4회 모두 등원, 선생님 60% → 기본 84,000원, 세금 2,772원, 최종 81,228원.
- 세금은 `기본급여 × 0.033`을 내림한다(반올림 정책은 미확정이라 한 곳의 정책 상수로 관리).
- 급여 설정이 비어 있으면 화면이 깨지지 않고 "설정 확인 필요"로 표시하며 지급할 수 없다. 지급할 금액이 0원이면 지급 버튼을 막고 이유를 알린다.
- "지급 확정"은 지급일(기본 오늘)과 함께 입출입내역에 지출을 같은 시점에 기록하고, 같은 선생님·같은 달은 한 번만 지급된다(급여 형태가 바뀌어도 중복 지급 불가). "지급 취소"는 확인을 거쳐 연결된 지출 행을 삭제하고 미지급으로 되돌린다. 지급 후 그 달 등원 기록이 바뀌면 지급액은 그대로 두고 경고만 보여 준다.
- **지급 확정 직전 재확인**: 화면은 해당 월을 다시 불러와 금액과 등원 수업을 비교한다. 서버는 출결 목록, 월급·시급·비율제 급여, 3.3% 세금과 지급 월을 검증한다. 비율제의 학생별 금액도 서버가 계산해 총액과 일치시켜 지급과 함께 보존하며, 수업별 금액을 확인할 수 없으면 지급을 보류한다.
- 원장은 선생님별 월 전체 정산 문자를 편집하고 클립보드에 복사할 수 있다. 발송 기능은 제공하지 않는다. `설정 → 선생님`에서 기본 템플릿을 바탕으로 사용자 템플릿을 추가·수정·삭제하고 지원 변수와 미리보기를 확인한다. 이전 지급 건처럼 당시 학생별 상세가 보존되지 않은 경우 확정 총액만 채우고 상세는 직접 확인하도록 안내한다.

전체 수입:

- 연도를 고르면 연간 수입·지출·순수익(수입 − 지출)과 월별 수입·지출·순수익을 보여 주고, 분류별 수입은 수입 내역만 집계한다. 수입·지출·순수익의 source of truth는 입출입내역이다.
- 선택한 월의 수납/미납 현황(입금 완료·미입금·미납 인원과 금액)과 미납 인원 목록을 함께 보여 준다.
- 그래프는 세로 막대(y축 눈금, 막대 위 수치 라벨, 1~12월)이며 지표 4종 중 하나를 고른다: 악기 전체(수납 완료 월수강료의 악기별 합계), 악기별(고른 악기 하나의 월별 수납 완료 금액), 학원 수입(입출입내역 수입 전체), 지출(입출입내역 출금 전체). 단일 연도만 보고, 스크린리더용 대체 표를 함께 제공한다. 악기 지표는 입금 완료된 월 수강료(청구월), 학원 수입·지출은 입출입내역(발생일) 기준이라는 안내를 그래프 아래에 보여 준다. 연간 합계와 그래프는 선택한 연도의 원장을 연도 단위로 읽어 계산한다.
