# PDF 이미지 확인 노트

## 전제

PDF에 포함된 이미지는 필수 구현 자산이 아니라 예시 화면이다. 구현 시 이미지를 그대로 재현하지 않고, 기능 흐름과 운영 UI 패턴만 참고한다.

## 페이지별 이미지 메모

- 4페이지: 레슨 시간표 섹션 진입 전 색상 막대 예시가 있다. 필수 스타일은 아니다.
- 7~8페이지: 개인레슨 시간표 보내기/복사 흐름으로 보이는 폼과 요약 카드 예시가 있다. 실제 구현에서는 문자 전송 대신 텍스트 복사 흐름을 우선한다.
- 10, 12, 13페이지: 원생 등록/관리 폼 예시가 있다. 악기별 상세 설정이 동적으로 늘어나는 폼 구조를 설계할 때 참고한다.
- 14~15페이지: 선생님 등록과 급여 형태 입력 예시가 있다. 급여 유형별 조건부 필드를 고려한다.
- 16~17페이지: 교재 관리 예시 화면이 있다. 등록, 재고, 구매 목록, 출고, 결제 완료가 탭 또는 단계형 테이블로 보일 필요가 있다.
- 18~20페이지: 수입 관리 탭과 그래프 예시가 있다. 운영형 테이블과 월/연도 그래프를 조합하는 방향으로 참고한다.
- 21페이지: 역할별 권한 표와 데이터 연동 요약이 있다. 권한/RLS 테스트의 기준으로 사용한다.

## 디자인 반영 원칙

- 예시 이미지는 기능 흐름 참고용이다.
- shadcn/ui 기반으로 재해석한다.
- 테이블, 탭, 폼, 다이얼로그, 배지, 사이드바 중심의 조용하고 밀도 있는 관리자 UI로 만든다.
- 예시 이미지의 색상이나 구체적 레이아웃을 그대로 따를 필요는 없다.
