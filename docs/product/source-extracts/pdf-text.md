# PDF 텍스트 요약

## 프로젝트 개요

더 클래식 음악학원의 레슨 일정, 회차권, 원생/선생님 정보, 교재 판매, 수입/지출을 하나의 화면에서 관리하는 자체 학원관리 시스템을 만든다. 기존 엑셀/수기 관리와 SaaS 구독료 부담을 줄이고, 학원이 직접 소유하고 필요에 맞게 고쳐 쓸 수 있는 시스템이 목표다.

## 핵심 문제

- 회차권 잔여 횟수 수기 계산 오류
- 원생 정보, 일정, 수강료 내역 분산
- 선생님 급여, 특히 비율제 급여 계산 시간 증가
- 수강료 미납 누락
- 기존 SaaS의 구독료 부담, 불필요한 기능, 커스터마이징 어려움

## 1차 범위

- 역할별 로그인: 원장, 데스크 직원, 선생님
- 레슨 시간표: 학원 피아노 레슨표, 개인레슨표
- 회차권 관리
- 원생/선생님/거래처 관리
- 휴원/퇴원 관리
- 교재 관리
- 학원 수입 관리와 수납/미납 현황

## 후순위 범위

- 그룹수업 정원/대기자 명단
- 카드 단말기 결제 연동
- 카카오 알림톡 자동 발송
- 학부모용/강사용 별도 모바일 포털
- 멀티 학원 SaaS
- 공지사항/이벤트 공유 기능

## 가장 중요한 도메인 규칙

레슨 일정에 등록되어 있다는 이유만으로 회차권을 차감하지 않는다. 실제 등원 확인을 눌렀을 때만 해당 원생/악기 회차권에서 1회 차감한다. 결석은 회차를 차감하지 않는다.

## 주요 기능 묶음

- 레슨 시간표: 반복 일정, 출석/결석, 결석 인원 목록, 보강/패스, 월별 메모, 개인레슨 등록, 시간표 텍스트 복사
- 회차권: 신규 등록, 기존 회차권에 회수/기간 추가, 수동 수정, 자동 차감, 소진/만료 임박 표시
- 원생 관리: 기본정보, 복수 악기, 악기별 담당 선생님/수업형태/요일/진도/레슨비/할인/최종 수강료
- 선생님 관리: 담당 파트, 연락처, 주민등록번호, 월급제/시급제/비율제 급여 설정
- 휴원/퇴원: 원생 상태 이동, 재원 처리, 휴원에서 퇴원 이동, 퇴원 30일 보관 후 삭제
- 거래처: 거래처명, 연락처, 종류, 비고
- 교재: 등록, 재고, 구매 목록, 출고, 결제 완료
- 학원 수입: 고정 수입, 입출입 내역, 교재 내역, 선생님 월급, 전체 수입과 그래프
